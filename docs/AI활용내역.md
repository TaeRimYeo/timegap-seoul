# AI 활용 내역

## 1. 분석 기법으로서의 통계·ML (보고서 '분석과정 및 방법')
| 기법 | 도구 | 용도 |
|---|---|---|
| 고차원 고정효과 가중 회귀(OD쌍 87,574개 + 구간×요일) | pyfixest 0.60 | 같은 OD의 시간대별 공급-차량 비중 연관(3-2) |
| 출발 동 블록 부트스트랩(200회), 동 부트스트랩(1,000회) | numpy, multiprocessing | 계수·배출·집중지수 불확실성 |
| 이중차분(동×구간, 일×구간 고정효과) | pyfixest | 2026-01 버스 파업 반응(3-3) |
| 한계효과 기반 탐욕 재배분 | pandas | P2 시뮬레이션 |
| 공간 연산(버퍼·중첩·점-폴리곤) | geopandas | 공간 접근성, 정류소·역 배정, 생활인구 코드 대응 |
보완 ML(LightGBM·SHAP 등)은 쓰지 않았다(Tier 3).

## 2. 작업 보조 생성형 AI
- 서비스: Anthropic **Claude Code** (모델 Claude Opus 5.5), 2026-10-16~ 세션. 하위 에이전트 1개를 배출계수·정책 원문 검색에 사용.
- 사용 범위
  | 작업 | AI가 한 일 | 사람/검증 |
  |---|---|---|
  | 데이터 구조 확인 | zip 해제, duckdb 프로파일링, 매뉴얼·레이아웃 내려받기·판독 | 코드표는 레이아웃 xlsx 원문으로 확정 |
  | 데이터 수집 | 공개 다운로드 경로로 2025-09 생활인구, 2026-01 버스·생활이동, 주민등록, 경계, OSM 역 수집 | data/README.md에 출처 기록 |
  | 코드 작성·실행 | src/ 전 스크립트, run_all.py | 모든 결과는 코드 재실행으로 재현 |
  | 출처 검색 | 배출계수·정책·뉴스 원문 검색, 인용문 추출 | IPCC 표·에너지법 별표는 PDF에서 직접 추출 확인, 나머지는 참가자 재확인 목록(저장소 미포함) |
  | 그림·보고서 | matplotlib 그림, python-docx 보고서(숫자는 결과 파일에서 자동 삽입) | 수치대조표 outputs/10_수치대조표.csv |
  | 사람 | 주제 확정, 9월 원자료 다운로드, 검토, 서명, GitHub push, 제출 | |
- 주요 프롬프트(요지): "확정 주제의 분석·보고서·프로토타입을 끝까지 완성하라. 데이터에서 확인하지 않은 수치·통계·인용·출처를 만들지 않는다. 가정은 가정으로 표시하고 출처와 민감도를 함께 쓴다. 상관을 인과로 쓰지 않는다. 생활이동은 통신 기반 추정치임을 밝힌다." 전문은 작업 지시서(저장소 미포함).
- AI가 스스로 바로잡은 사항(기록): ① 지하철 공급을 동 안 역 수에서 800m 피복 가중으로 변경(공간 기준과 불일치 발견) ② 대표 OD 1쌍 그림을 잔차 binscatter로 교체(선택 편향 우려) ③ 낮 시간 안의 변동만으로는 관계가 약하다는 점을 발견해 보고서에 명시하고 파업 시간대별 분석으로 보완 ④ 생활인구 코드 대응에서 한강 수면 처리 차이로 생긴 가짜 분할 제거.
- 외부 심사 반영(2026-10-22): 생성형 AI(claude.ai 별도 대화)로 모의 심사를 받았다. 참가자가 두 가지를 결정해 지시했다: ① 낮 시간 배출 주장을 시간대별 계수와 파업 차량 통행 수로 다시 검정하고, 약하면 헤드라인에서 뺀다 ② CNG 증회 결론을 승용차 계수를 올려 재검증한다. AI는 src/03i_band_beta.py·04c_band_carbon.py를 작성·실행했다. 결과에 따라 탄소 헤드라인을 심야·새벽 6,679 t/년으로 바꾸고, 공통 계수 2.8만 t는 상한 시나리오로 낮췄다. CNG 결론은 유지됐다(계수 3배에도 순감축 6셀 이하).
