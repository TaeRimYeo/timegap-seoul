# 같은 동네, 다른 시간 — 지도에 없는 '시간 사각지대'가 만드는 차량 이동과 탄소

AI와 함께하는 교통문제 해결을 위한 데이터 분석 공모전(재단법인 숲과나눔 × 한겨레) 분석 코드 · 여태림

## 문제
서울시는 지하철역·중앙/가로변 버스전용차로 800m 이내 여부(ART 지표)로 대중교통 사각지대를 전수조사한다고 발표했다(2026-08-21). 800m 기준은 '어디에' 정류장이 있는지만 본다. 이 저장소는 같은 동네가 '언제' 사각지대가 되는지(시간 사각지대)를 서울 생활이동 OD×수단 데이터와 버스 운행횟수로 찾아, 차량 이동·탄소·고령 부담과의 관계를 계산한다.

## 핵심 결과 (2026년 9월 화~목 6일·토·일 4일, 코드 출력 그대로)
| | 값 | 근거 파일 |
|---|---|---|
| 800m 기준 '양호' 357동 중 시간 사각지대 셀 보유 | **95동(26.6%)**, 민감도 11~37% | `outputs/03_요약.json`, `03_민감도.csv` |
| 같은 OD에서 출발지 공급 log 1단위 낮을 때 차량 비중 | **+3.4%p** (부트스트랩 95% 1.7~5.1%p, 연관) | `outputs/03_회귀표.csv`, `03_부트스트랩.csv` |
| 시간대별 계수(그 시간대 안 변동만): 심야 출발지 / 새벽 도착지 / 주간 | **−8.0%p** / **−25.9%p** / 주간 출발 +2.3%p(p=0.26)·도착 +3.2%p(반대 부호) | `outputs/03_회귀표_시간대분리.csv` |
| 심야·새벽(22–07시) 연관 추가 배출 (헤드라인) | **6,679 tCO₂/년** (부트스트랩 95% 2,120~11,289) | `outputs/04c_시간대별_탄소.json` |
| 시간대 공통 계수 가정(상한 시나리오, 헤드라인 아님) | 28,124 tCO₂/년 (그중 92.9%가 심야 밖) | `outputs/04_탄소.json` |
| 공백 노출 집중지수(65세 이상 비율 순) | **0.212** (95% 0.094~0.325) | `outputs/03_집중지수_부트.json` |
| 버스 파업일 버스 의존 동: 차량 비중 / 차량 통행 수(낮 07–22시) | **+5.1%p** / 버스 비중 1단위, 차량 통행 수 −1.3%(95% −8.4~+6.2, 늘지 않음) | `outputs/03_파업_시간대별.csv`, `03_파업_차량통행.csv` |
| p75까지 CNG 증회 | 1,312셀 **전부** 순배출 증가. 승용차 계수 3배·재차 1.2에서도 순감축 1~6셀 | `outputs/05_수단비교.json`, `04c_CNG_민감도.csv` |
| 같은 구 안 낮 비첨두 → 새벽·심야 재배분(총 운행·버스km 불변, 첨두 유지) 상위 20셀 | **512 tCO₂/년** 순감축 (420~598), 1회당 0.53 kg (시뮬레이션) | `outputs/05_재배분_시간대_첨두제외.json` |

한계: 생활이동은 KT 통신 기반 추정치(30분 미만 체류 미집계), 연관≠인과, 행정동 생태학적 지표, 주간(07–22시)에는 공급-차량 관계가 확인되지 않음(평상시·파업 모두), 새벽 계수는 평일·주말 대비로만 식별, 승용차 계수는 신차 공인값, 재차인원은 가정.

## 실행 순서
```bash
pip install -r requirements.txt
# data/README.md 대로 원자료를 data/raw/, data/external/ 에 둔다
python -I run_all.py            # 전체 (약 10분, 부트스트랩 포함)
python -I run_all.py 03_model   # 특정 단계부터
```
| 단계 | 스크립트 | 산출 |
|---|---|---|
| 0 데이터 구조 | `src/00_profile.py`, `00_codecheck.py` | `00_데이터구조.md`, `outputs/logs/` |
| 1 공급·공간 접근성 | `src/01a_osm_stations.py`, `01_supply.py` | `outputs/01_*` |
| 2 OD 추출·패널·형평성 | `src/02a_od_extract.py`, `02b_panel.py`, `02c_equity.py` | `data/interim/`, `outputs/02_*` |
| 3 모형·사각지대·형평성·파업 | `src/03_model.py` … `03h_strike_bands.py` | `outputs/03_*` |
| 4 탄소·재배분 | `src/04_carbon.py`, `04b_reallocation.py`, `05_modes.py` | `outputs/04_*`, `05_*` |
| 6 그림 | `src/06_figures.py` | `figures/` |
| 7 프로토타입 데이터 | `src/07_app_data.py` | `app/data/` |
| 8 보고서 | `src/08_report.py --pdf` | `report/`, `outputs/10_수치대조표.csv` |

계수·가정: `src/params.json`(원문 확인 여부·출처 포함). 문서: `00_데이터구조.md` ~ `05_정책.md`, `07_서비스설계.md`, `docs/AI활용내역.md`.

## 프로토타입 「서울 버스시계(T-ART)」
`app/index.html`을 브라우저로 열면 된다(서버 불필요, Leaflet 1.9.4). 시간 슬라이더·평일/주말·'공간 양호·시간 사각지대' 강조, 동 카드(시간대별 공급, 공백 노출, 수단별 순감축 시뮬레이션). URL 해시로 상태 지정 가능: `index.html#dt=wk&tb=12-16&dong=11350600&good=1`.

## 데이터·라이선스
원자료는 저장소에 넣지 않는다. 출처·다운로드 방법·이용 조건은 `data/README.md`. `outputs/`에는 행정동×시간 구간 집계만 있다(개인정보 없음).
